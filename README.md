# Samsung TV Pro

واجهة رئيسية خفيفة واحترافية لشاشات سامسونج الذكية (Tizen)، مع دليل لتسريع الشاشة وتخفيفها.

**الطراز المستهدف:** Samsung Crystal UHD **CU7000** (2023، Tizen 7.0) — مثل `UA65CU7000UXSA`. التفاصيل في [`docs/DEVICE-CU7000.md`](docs/DEVICE-CU7000.md).

## ماذا يقدّم المشروع

1. **مشغّل تطبيقات احترافي** (`app/`): تطبيق ويب لنظام Tizen يُستخدم كواجهة رئيسية بديلة:
   - بلا إعلانات ولا توصيات ولا معاينات تلقائية.
   - 5 سمات جاهزة: داكن احترافي، مكتبي فاتح، تباين عالٍ، لافتات رقمية، استوديو محايد.
   - مفضّلة قابلة للتخصيص، تُحفظ على الشاشة.
   - **وضع الأداء**: يوقف الحركة ويستبدل الأيقونات بأحرف — مفعّل افتراضياً على الشاشة لأن معالج CU7000 محدود.
   - **يعمل بالأسهم وOK فقط**: شريط أوامر أسفل الشاشة + ضغط مطوّل على OK، لأن ريموت CU7000 قد يكون بلا أزرار ملوّنة.
   - واجهة عربية (RTL) بدقة 1080p، تعمل بالريموت فقط.
2. **دليل التحسين** ([`docs/OPTIMIZATION.md`](docs/OPTIMIZATION.md)): الإعدادات التي توقف الخدمات الثقيلة (ACR، الإعلانات، Bixby، التشغيل التلقائي) وتسرّع الاستجابة.
3. **سكربت النشر** (`scripts/deploy.sh`): يغلّف التطبيق ويثبّته على الشاشة بأمر واحد.

> **ملاحظة:** المشروع لا يعدّل فيرموير Tizen، فهو موقّع ومحمي بـ Secure Boot، وتعديله قد يُعطّل الشاشة.
> كل ما هنا يعمل عبر وضع المطوّر الرسمي، ويمكن التراجع عنه بحذف التطبيق.

## أزرار الريموت

| الزر | الوظيفة |
|---|---|
| الأسهم / OK | التنقل وتشغيل التطبيق |
| ⬇ حتى أسفل الشاشة | شريط الأوامر (بديل الأزرار الملوّنة) |
| 🔴 أحمر | تبديل السمة |
| 🟢 أخضر أو **ضغط مطوّل على OK** | إضافة/إزالة من المفضّلة |
| 🟡 أصفر | وضع الأداء |
| 🔵 أزرق | تحديث قائمة التطبيقات |
| Back | إخفاء الواجهة |

## المعاينة على الكمبيوتر

افتح `app/index.html` في المتصفح، فهو يعمل ببيانات تجريبية. استخدم الأسهم وEnter، والأزرار `R` و`G` و`Y` و`B` بدلاً من الأزرار الملوّنة.

## التثبيت على الشاشة

1. **ثبّت [Tizen Studio](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html)** مع إضافتي *TV Extensions* و*Samsung Certificate Extension*.
2. **فعّل وضع المطوّر على الشاشة:**
   افتح Apps، ثم اكتب `1 2 3 4 5` بالريموت، ثم فعّل Developer Mode وأدخل IP جهازك، ثم أعد تشغيل الشاشة.
3. **اعرض DUID الشاشة** (إلزامي لطرازات 2023):
   ```bash
   ./scripts/tv-info.sh <TV_IP>
   ```
4. **أنشئ شهادة Samsung** من Certificate Manager باسم `samsungtv`، والصق الـ DUID في خطوة Distributor Certificate.
5. **انشر التطبيق:**
   ```bash
   ./scripts/deploy.sh <TV_IP>
   ```
6. ثبّت **Samsung TV Pro** في أول شريط الشاشة الرئيسية، وفعّل **Autorun Last App** ليفتح تلقائياً عند تشغيل الشاشة.

## هيكل المشروع

```
app/
  config.xml        إعدادات تطبيق Tizen والصلاحيات
  index.html        الواجهة
  css/base.css      التخطيط
  css/themes.css    السمات (متغيرات CSS فقط)
  js/apps.js        الوصول لتطبيقات الشاشة + بيانات المعاينة
  js/main.js        التنقل، السمات، المفضّلة، وضع الأداء
scripts/deploy.sh   التغليف والتثبيت
scripts/tv-info.sh  عرض DUID وإصدار Tizen للشاشة
docs/OPTIMIZATION.md دليل التسريع والإعدادات الاحترافية
docs/DEVICE-CU7000.md ملف الطراز المستهدف وملاحظاته
```

## إضافة سمة جديدة

1. انسخ كتلة من `app/css/themes.css` وغيّر اسمها والألوان.
2. أضف `{ id: 'اسم-السمة', label: 'الاسم الظاهر' }` إلى مصفوفة `THEMES` في `app/js/main.js`.
