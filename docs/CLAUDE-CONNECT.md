# كيف تجعل Claude يتحكم بشاشتك مباشرة

الأداة `tools/tvctl.py` تُرسل الأوامر للشاشة، والملف `CLAUDE.md` يشرح لـ Claude كيف يستخدمها في كل جلسة.
يكفي أن تكتب لـ Claude طلباً مثل: **"شغّل يوتيوب على الشاشة"**، أو **"اخفض الصوت إلى 10"**، أو **"حوّل إلى HDMI2"**.

هناك طريقتان، ويمكنك تفعيل الاثنتين معاً:

| | الطريقة 1: SmartThings (سحابي) | الطريقة 2: من جهازك (محلي) |
|---|---|---|
| تعمل من | أي مكان، حتى من الجوال وجلسات Claude السحابية | جهاز كمبيوتر على نفس شبكة الشاشة |
| التشغيل والإطفاء | ✓ (حتى لو كانت الشاشة مطفأة) | إطفاء ✓، تشغيل عبر Wake-on-LAN |
| الصوت والمصدر | ✓ رقم محدد، HDMI1/2 | أعلى/أخفض فقط |
| أزرار الريموت | الأساسية (أسهم، OK، رجوع، Home) | **كل** الأزرار |
| قائمة التطبيقات وفتح الروابط | ✗ | ✓ |
| تثبيت تطبيق Samsung TV Pro | ✗ | ✓ |

---

## الطريقة 1: SmartThings (ابدأ بها، فهي الأسهل)

1. **أضف الشاشة إلى تطبيق SmartThings** على جوالك: افتح التطبيق، ثم اضغط ➕، ثم "جهاز"، ثم "تلفزيون"، ثم Samsung. سجّل الدخول على الشاشة بنفس حساب Samsung.
2. **أنشئ توكن شخصي** من: `account.smartthings.com/tokens`، ثم "Generate new token".
   - الاسم: `Claude TV`
   - الصلاحيات: فعّل **Devices** (List, See, Control).
   - انسخ التوكن، فهو يظهر مرة واحدة فقط.
3. **أعطه لـ Claude بأمان:** عندما يطلبه Claude سيظهر لك نموذج آمن. الصق التوكن فيه، **وليس في المحادثة**. يُحفظ في إعدادات البيئة السحابية، ولا يراه Claude نفسه.
4. اطلب من Claude: "اربط الشاشة عبر SmartThings". سيعرض أجهزتك ويختار الشاشة.

## الطريقة 2: Claude على جهازك (تحكم كامل)

جلسات Claude السحابية لا تصل إلى شبكتك المنزلية. لذلك يجب تشغيل Claude على كمبيوتر متصل بنفس الراوتر الذي تتصل به الشاشة:

1. **على الكمبيوتر:** ثبّت Python 3 و Git، ثم انسخ المشروع:
   ```bash
   git clone https://github.com/ialshareef/state.git samsung-tv
   ```
2. **اعرف IP الشاشة:** الإعدادات ← عام ← الشبكة ← حالة الشبكة ← إعدادات IP.
3. **اسمح بالتحكم من الشبكة:** الإعدادات ← عام ← مدير الأجهزة الخارجية ← فعّل "Device Connection Manager"، واجعل "Access Notification" مفعّلاً.
4. **اربط الأداة لأول مرة** (سيظهر طلب على الشاشة، اختر **سماح**):
   ```bash
   cd samsung-tv && python3 tools/tvctl.py setup --ip 192.168.1.50
   ```
5. **شغّل Claude في مجلد المشروع**، بإحدى طريقتين:
   - تطبيق **Claude Desktop**: افتح مجلد `samsung-tv` كمشروع في Claude Code.
   - أو من الطرفية، لتتحكم من جوالك عبر تطبيق Claude:
     ```bash
     claude remote-control
     ```
6. لتفعيل **التشغيل من وضع الإطفاء** محلياً: الإعدادات ← عام ← الشبكة ← إعدادات الخبير ← فعّل "التشغيل بالجوّال" (Power On with Mobile).

## أمثلة على طلبات يمكنك قولها لـ Claude

- "ما حالة الشاشة الآن؟"
- "شغّل الشاشة وافتح يوتيوب"
- "اضبط الصوت على 12 وحوّل إلى HDMI1"
- "افتح تطبيق Samsung TV Pro"
- "اعرض قائمة التطبيقات المثبتة"
- "افتح هذا الرابط على الشاشة: ..."
- "ثبّت آخر نسخة من تطبيق Samsung TV Pro على الشاشة" (محلي، يتطلب Tizen Studio)

## الأمان

- التوكن ورمز الربط يُحفظان في `.tv/config.json`. هذا الملف مستثنى من Git ولا يُرفع للمستودع.
- يطلب Claude تأكيدك قبل إطفاء الشاشة أو قطع ما يُعرض عليها.
- لإلغاء صلاحية Claude: احذف التوكن من `account.smartthings.com/tokens`، أو احذف الجهاز من "مدير الأجهزة الخارجية" في الشاشة.
