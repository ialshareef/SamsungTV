# دليل تخفيف وتسريع شاشة سامسونج (Tizen)

كل الخطوات هنا من إعدادات الشاشة الرسمية — آمنة وقابلة للتراجع ولا تُلغي الضمان.
أسماء القوائم قد تختلف قليلاً حسب سنة الطراز. الطراز المستهدف: **CU7000 (2023، Tizen 7.0)** — تفاصيله في [`DEVICE-CU7000.md`](DEVICE-CU7000.md).

## 1. إيقاف الخدمات التي تستهلك المعالج والشبكة

| الإعداد | المسار | الفائدة |
|---|---|---|
| خدمات معلومات المشاهدة (ACR) | الإعدادات ← الدعم ← الشروط والخصوصية ← إيقاف "Viewing Information Services" | يوقف تحليل ما يُعرض على الشاشة في الخلفية |
| الإعلانات المخصصة | نفس المسار ← "Interest-Based Advertisement" ← إيقاف | تقليل الإعلانات وطلبات الشبكة |
| التشغيل التلقائي لـ Smart Hub | الإعدادات ← عام ← ميزات Smart ← إيقاف "Autorun Smart Hub" | إقلاع أسرع بدون تحميل واجهة سامسونج |
| تشغيل آخر تطبيق | نفس المسار ← **تفعيل** "Autorun Last App" | يفتح Samsung TV Pro تلقائياً عند التشغيل (انظر [ملف CU7000](DEVICE-CU7000.md)) |
| معاينة القنوات/المحتوى | الإعدادات ← عام ← ميزات Smart ← إيقاف "Auto Run Preview" | واجهة رئيسية أخف |
| المساعد الصوتي | الإعدادات ← عام ← الصوت ← إيقاف Bixby / Voice Wake-up | يحرّر الذاكرة ويوقف الاستماع الدائم |
| التحديث التلقائي للتطبيقات | Apps ← الإعدادات ← إيقاف Auto Update | يمنع التحديثات أثناء العروض |
| Ambient / Art Mode | الإعدادات ← عام ← إيقاف وضع Ambient التلقائي | توفير الطاقة والذاكرة |

## 2. تسريع الاستجابة

- **التشغيل الفوري**: الإعدادات ← عام ← إدارة النظام ← فعّل "Instant On" (إقلاع في ثوانٍ).
- **وضع الألعاب / Auto Low Latency**: للعروض التفاعلية وأجهزة الكمبيوتر — يقلل تأخير الإدخال بشكل كبير.
- **إلغاء تثبيت التطبيقات غير المستخدمة**: Apps ← الإعدادات ← حدد التطبيق ← حذف.
- **مسح ذاكرة التخزين المؤقت**: الإعدادات ← الدعم ← العناية بالجهاز ← "Clean Now" / "Manage Storage".
- **إعادة تشغيل كاملة أسبوعياً**: اضغط مطولاً على زر التشغيل في الريموت حتى يظهر شعار سامسونج (Cold Boot).
- **الشبكة السلكية (Ethernet)** بدلاً من Wi-Fi للعروض والبث.

## 3. إعدادات الصورة للاستخدام الاحترافي

| الاستخدام | وضع الصورة | ملاحظات |
|---|---|---|
| عروض تقديمية / مكتب | Standard | أوقف Eco Sensor إذا كانت الإضاءة ثابتة |
| مونتاج وتصحيح ألوان | Filmmaker Mode أو Movie | Color Tone: Warm2، أوقف Contrast Enhancer و Auto Motion Plus |
| شاشة كمبيوتر | Game Mode + "PC" كأيقونة للمصدر | يفعّل 4:4:4 Chroma لنص واضح |
| لافتات رقمية | Dynamic + إطفاء Auto Power Off | فكّر في سلسلة شاشات Samsung Business مع MagicInfo |

## 4. الوضع الاحترافي المتقدّم

- **قفل الشاشة على مصدر/تطبيق واحد**: استخدم تطبيق Samsung TV Pro في هذا المشروع كواجهة رئيسية، وثبّته في أول شريط الرئيسية.
- **قائمة الخدمة (Hotel/Service Menu)**: موجودة لكنها مخصصة للفنيين، وتغيير إعداداتها قد يعطّل الشاشة — **لا يُنصح بها**.
- **للاستخدام المؤسسي على نطاق واسع**: شاشات Samsung Business تدعم MagicInfo و Tizen Kiosk Mode رسمياً.

## لماذا لا نعدّل الفيرموير نفسه؟

فيرموير Tizen موقّع رقمياً ومحمي بـ Secure Boot. تعديله يتطلب استغلال ثغرات أمنية في الطراز تحديداً، وعادةً ما يُغلقها أول تحديث. وأي خطأ قد يُعطّل اللوحة الأم نهائياً (Brick). لهذا يعمل المشروع على **طبقة التطبيقات والإعدادات** فقط.
